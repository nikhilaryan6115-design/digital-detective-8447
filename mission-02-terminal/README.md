## 3. Commands / tools used
* `pwd`: Display current working directory path.
* `ls`, `ls -l`, `ls -lah`: Directory listing with flags for hidden files, permissions, and human-readable sizes.
* `cd`: Change directory.
* `mkdir`: Create directories.
* `touch`: Create empty files.
* `echo "text" >> file`: Append text to file without overwriting.
* `cp`: Duplicate files.
* `mv`: Move and rename files.
* `cat`: Display file contents.
* `head`: Display top lines of output.
* Pipe operator (`|`): Redirect output of one command as input to another.

## 4. My understanding
The command line provides direct, efficient control over the filesystem and system utilities. Using command flags customizes command output, while pipes allow chaining modular tools together to filter and process streams of data.
