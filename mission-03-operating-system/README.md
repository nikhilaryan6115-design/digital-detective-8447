# Mission 3 — Understand the operating system

## 1. Task / objective
Explore the operating system environment, inspect running processes, examine storage, paths, and file permissions, and describe core operating system responsibilities.

## 2. Work completed
* Explored operating system environment details, user identity, and storage capacity using terminal commands.
* Inspected active processes, understood the Process ID (PID) column, and identified running application and daemon processes.
* Navigated between directories, analyzed absolute vs. relative paths, and examined file permissions (`r`, `w`, `x`) for file ownership.
* Documented core OS responsibilities (process, memory, device, file management, UI/shell, and security) with practical examples in `mission-03-operating-system/notes.md`.

## 3. Commands / tools used
* `uname -a`: Displayed kernel and operating system details.
* `whoami`: Verified current user identity.
* `df -h`: Inspected filesystem disk space in human-readable format.
* `ps aux` / `ps`: Viewed running system processes and PIDs.
* `pwd`, `cd`: Navigated paths and demonstrated relative vs. absolute directory navigation.
* `ls -l`: Inspected file permission strings.

## 4. My understanding
The operating system acts as the intermediary between computer hardware and software applications. It coordinates hardware resources (CPU, RAM, storage, peripherals), isolates and schedules processes, protects files through granular permission schemes, and presents a command-line shell or graphical interface for interaction.
