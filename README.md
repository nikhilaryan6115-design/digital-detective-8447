## 1. Introduction
The **Digital Detective** assignment is an independent learning investigation designed to explore how computers work from the ground up. Through hands-on Terminal operations, operating system investigations, data representation exercises, Python scripting, and Git/GitHub version control workflows, this project documents essential computer science concepts into a mini system report.

## 3. Topics Explored
* **Computer Fundamentals:** The Input-Process-Output-Storage (IPOS) cycle, hardware components, and software classifications.
* **Terminal Operations:** Command-line navigation, file creation and manipulation, command flags, and output piping.
* **Operating Systems:** Process management, Process IDs (PIDs), memory management, filesystem paths, and file permissions.
* **Program Execution:** Differences between compiled and interpreted languages, and executing Python scripts.
* **Data Representation:** Converting between decimal, binary, and hexadecimal number systems, and text encoding standards (ASCII and UTF-8).
* **Version Control:** Git workflow (init, status, add, commit, log), branching, Pull Requests, and remote synchronization.
* **Networking:** Local Area Networks (LAN), Wide Area Networks (WAN), DNS resolution, routing, protocols, and website request lifecycles.

## 4. How to Run the Number Converter
The repository includes an interactive Python number converter developed in Mission 5. To run the converter from Terminal:

```bash
cd mission-05-numbers-data
python3 number_converter.py
```
Enter any positive decimal number when prompted to see its binary and hexadecimal representations.
